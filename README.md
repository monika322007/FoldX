# FoldX

Landing page for FoldX, a folding board that folds shirts, tops and trousers neatly in under 3 seconds.

- Single FoldX: ₹199
- Combo Offer (2 boards): ₹349
- Orders: customers fill in the order form and send the message to support@foldx.com

## Files

- `index.html`: the whole website (HTML, CSS and JavaScript in one file)

## Run locally

Open `index.html` in any browser. No build step is needed.

## Deploy with GitHub Pages

1. Push `index.html` to the `main` branch of a public repository.
2. Open the repository, then Settings, then Pages.
3. Under Build and deployment, set Source to "Deploy from a branch".
4. Choose branch `main` and folder `/ (root)`, then press Save.
5. After about a minute the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Edit the site

- Prices: search for `₹199` and `₹349` in `index.html`, and for `price:199` and `price:349` in the script at the bottom.
- Email: search for `support@foldx.com` and replace every match.
